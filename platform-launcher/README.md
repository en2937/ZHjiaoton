# 一键启动校园交通平台

双击项目根目录的 **一键启动平台.cmd**。程序自动识别当前校园网 IP，启动或复用沙盘、师生问答、管理员登录和校园网入口；检查通过后输出四个访问地址，并自动打开本机管理员登录页。

地址同时保存在根目录 **平台访问地址.txt**。把其中“校内查看沙盘”和“校内师生问答”地址发给其他校园网用户即可。

## 使用时会发生什么

- 已运行且健康的服务会被复用。重复启动不会重置、暂停或重启正在运行的沙盘，也不会产生重复服务。
- 支持最新沙盘的统一时钟和问卷分批出发场景。启动结束前会通过实际校园网入口读取沙盘及师生状态，核对仿真轮次、实例、时钟起点、出发场景及配置；明显滞后或场景不一致时报告失败，不把健康检查通过当成全部接通。正常运行期间不同请求的时钟允许有几秒差异。
- 启动窗口和地址文件会显示当前场景及检查时的沙盘时刻。启动器保留当前选择，不会自动启用问卷或将问卷场景切回固定需求。
- 若校园网 IP 改变，只重绑校园网与管理员入口，必要时用已有专用 CA 为新 IP 更新管理员叶证书。沙盘、师生后端及管理员账号保留；不会自动安装根证书或绕过 HTTPS 验证。新地址会重新显示并写入地址文件。
- 防火墙规则有效时不再请求授权；规则缺失或 IP 过期时，只请求 Windows 管理员授权放行 `10.0.0.0/8` 来源到当前校园网 IP 的 TCP 4180/4190。取消授权后明确提示尚未放行，已运行的服务保留。
- 端口被其它程序占用时停止启动流程并报错，不杀掉其它程序。项目服务正在初始化时会等待其健康检查通过。
- 每次启动保存只含运行状态的 `last-start.json`；故障说明在 `last-error.txt`，新增服务日志在 `logs/`。未复制或输出 Dify 密钥、账号哈希、桥接密钥、TLS 私钥。
- 启动锁避免同时双击产生两个启动流程；先前启动异常退出留下的锁会核对进程身份后清理。不会因为 PID 被其它程序重新使用而阻止启动。

## 当前范围

启动器直接连接项目目录中的现有服务。最新沙盘接入增加共享状态检查，不修改沙盘引擎、路网、网页、管理员认证、Dify 协议或原有启动脚本。运行中的服务通过检查时直接复用；后台代码更新仍需要相应部署流程，不会因双击就擅自重启正在运行的仿真。

若沙盘此前已经停止，新启动器启动现有服务的初始场景，不自动选择旧检查点。**不包含关机前自动保存、故障自动重启、后台持续监控或固定 IP**；这些可在后续恢复稳定性任务中独立推进。当前运行中的仿真会保留。

电脑需保持开机、不休眠并连接校园网。关闭启动窗口不会停止服务。没有校园网 10.x 地址时会明确报错，不生成错误的校内链接。重新联网后请再次启动查看最新地址。

管理员 HTTPS 的首次管理设备证书安装沿用 `admin-access/README.md`。校园网隔离、跨楼宇路由和校方部署手续仍取决于学校环境；本启动器只处理本机启动和已有校内入口。

## 验证

`node --test platform-launcher/tests/startup.test.mjs`：隔离测试重复启动、冷启动顺序、IP 更换、叶证书更换、外来端口、Windows 授权取消与真实 HTTP 健康检查。

最新接入另覆盖问卷场景保持、师生场景/时钟/轮次不一致及校园网实际数据路径不可用。与只读网关、新问卷引擎共26项测试通过。

实际启动验证使用与双击程序相同的 Windows PowerShell 5.1 入口，并加 `-NoBrowser`，避免验收时打断其它浏览器工作。运行状态输出、进程连续性和实际网络检查记录在 `VALIDATION.md`。

`verify-latest.mjs --before`、运行一键启动、再执行 `verify-latest.mjs` 可核对当前进程/场景连续性和校园网资源版本；`verify-chat.mjs` 会实际发送一条路线问题到已有学校AI服务，仅用于主动验收，不随日常启动自动调用。
