# 登录页 GSAP 背景动画

2026-10-15，按用户要求给登录窗口背后加入缓慢移动的虚化沙盘图样，保持浅色、冷静与实用的界面。

同日最新调整：按用户要求移除“暂停背景”按钮、样式及手动控制逻辑。背景自动播放，后台暂停、减少动态效果和高清登录镜头保留。正式页1440×900、390×844控件数量均为0，背景继续移动，无横向溢出或浏览器错误；8项交接检查通过。截图与记录在 `../ui-validation/login-no-pause/`，备份 `../_backup/20261015-144907-before-remove-background-control/`。下文首次验收中的暂停按钮操作属于历史记录。

## 实现

- 使用 GSAP 3.15.0 核心包，来源为官方 npm，归档 SHA-512 与注册表一致。许可证及版权声明保留，来源见 `vendor/gsap/PROVENANCE.md`。
- 静态背景取自现有校园底图，在只读预览页以 900px 宽渲染并保存，约 43KB；无车流圆点和路口队列标签，不读取或轮询实际沙盘。
- 单一背景图层使用固定的模糊、低饱和度与浅色遮罩。GSAP 只动画平移，桌面单程25秒，手机32秒，往返连续。前景表单不参与动画。
- 保留清晰的不透明登录窗口，背景自动播放，不显示手动暂停选项。
- 使用 `gsap.matchMedia()` 适配屏幕和 `prefers-reduced-motion`；减少动态效果时保持静态背景。`visibilitychange` 在文档隐藏时暂停，离开页面时清理，支持 BFCache 返回。
- 动画异常会回退到静态背景，认证脚本仍独立执行。原认证源码逐字保留在 `client/login-form.mjs`。

## 构建与维护

修改 `client/login.css`、`client/login-motion.mjs` 或 `client/login-form.mjs` 后，在项目根目录执行：

```powershell
node admin-access/build-login.mjs
```

生成现有白名单中的 `public/login.css` 和 `public/login.mjs`。GSAP 使用本地 CommonJS 容器接入模块脚本，浏览器无需访问 CDN。无需 npm install，也无需重启服务。请勿直接修改这两份生成文件。
