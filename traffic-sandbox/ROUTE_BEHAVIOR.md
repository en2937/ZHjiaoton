# 路线认知与尝试意愿分组

## 使用

管理员“场景设置 → 选路规则”选择“认知与意愿分组”。“引导覆盖”只表示给可绕行学生提供信息的目标覆盖，实际触达和实际绕行分别统计。“北侧绕行策略目标”继续使用既有策略抽签；学生还须满足认知、信息、意愿和时间条件。机动车及东北背景来车沿用原选路规则。

统计另列`selectionModes`和`bypassInherited`，区分当前分组规则下的选择与切换前沿用的已选路线；已过分岔点的旧绕行者不能算作新行为模型促成的绕行。

模式切换和调参不重新生成当前车辆属性，不清空车流。可切回“原选路规则”作对照；已经驶过分岔点的车辆保留路线和目的地。管理员 AI 可建议/调整引导覆盖，模式、问卷权重及行为假设只读。建议须确认，执行回执来自后端；相关配置变化后旧方案失效。撤回恢复设置，不消除已经传给出行者的信息，不让车辆瞬移或返回分岔点。

## 调查事实

有效样本36份，自报信息不代表全校学生。Q1认知人数：知道18、不知道14、知道但未走过4；听说过总计22人，问卷没有实际使用率。Q2意愿人数：更快后倾向继续32、愿意但不常走2、不愿意2；愿意总计34人，不等于实际AI引导接受人数。权重使用原始人数，不使用四舍五入百分比。

用户于2026-10-14确认调查“东教学楼到东区食堂便捷小路”就是沙盘绕过A的北侧环岛线。路线对应属于用户确认信息；把调查迁移到模型地点1、2的学生骑行人群仍是人群与行程迁移假设。

## 模拟假设

- 地点1、2出发的电动车/自行车视为学生骑行者；不套用机动车及北侧背景车辆。双向行程都迁移行为机制。
- 没有两题个人交叉资料，认知与意愿用两个独立随机序列分配。每36个生成的学生行程分别随机排列18/14/4与32/2/2名额。当前在场、入口等待及经过筛选的子群比例会随出入场变化，不强制等于问卷比例。
- 固定行为种子20261014，独立于车流随机序列。属性按行程序号生成并保存；调参、暂停、倍速和读取不会重抽。旧运行快照中现有学生按车辆ID顺序补充稳定属性；不重建历史已完成者身份。
- 不知道路线者须先获有效引导；知道但未尝试者首版也须获引导才试用。知道路线者具有必要信息，但仍不必然绕行。
- 引导以固定触达抽签与覆盖设定比较，仅向合法可达且尚未过分岔点者提供信息。信息在本行程内保留，降低覆盖或撤回不“取消已知信息”。
- 当前规则估算至少节省15秒才考虑小路；条件继续组试用概率0.8、不常用组0.35、不愿组0。概率与门槛均不是问卷测量结果。稳定试用抽签可重复，不能把94.44%意愿直接当成实际接受率。
- 条件继续只参与当前行程选择，没有跨行程身份、经验反馈或长期习惯学习。
- 每5模拟秒或配置变化复核分岔前路线。需要原目的地相同、两条路线均与已行驶路径连续；经过分岔点后不强行改道。
- 选路用时为全原目的地行程的自由流时间加当前队列服务和信号等待估算；不预测未来到达路况，不把当前估计叫作试用后的实测收益。AI另读取与师生端一致的1/2地点间路线秒数和约米数，主路约1.2km比例标定保持原假设。

## 统计口径

统一后端输出`behavior`，附运行ID、状态版本、配置版本、更新时间和模拟时刻。

| 字段 | 分母及时间范围 |
| --- | --- |
| onMap | 当前地图内学生骑行车辆；分别给认知、意愿、已引导、选绕行人数 |
| entryWaiting | 当前入口等待学生；独立统计，不混入地图内人数 |
| eligible | 当前地图内、北侧绕行合法且尚未经过分岔点的学生 |
| eligible.reasons | eligible中未选绕行者，使用当前行程最后一次选择原因，互斥计数；每5秒或配置变化更新 |
| ineligible | 路线不适用、已过分岔点分别单列；与eligible共同覆盖onMap |
| metrics.northBypass | 保留原全车型、当前线路车辆和累计生成统计，不能当作学生分组分母 |

未绕行原因按必要信息→意愿→节省门槛→试用抽签→策略抽签顺序判定。不知道且没有有效引导时：覆盖为0记“未获知”，覆盖已设置但尚未触达记“未触达”；未试过且无覆盖单列。“missingProfile/notEvaluated”明确标记无法解释的数据。已选择绕行人数是路线选择结果，可能尚在分岔前，不等于已经通过A的减少量。

## 管理员 AI 输入与数字校验

`campus-admin-v2`每轮从同一后端快照读取配置、统计、统一时钟、A/B及各路线条件；问卷权重和实际人数分开。无法读取行为状态时标记缺失。后端生成`behavior.facts`完整事实描述，带群体、时间范围、单位和条件；AI引用这些描述并列为证据，校验路径/版本后由后端填入。不允许把裸人数自行解释成另一群体，或把初始认知误称为引导后的认知。路线收益描述保留正负方向及“当前估算”，不能把条件继续意愿说成无条件长期使用。

模型只返回结构化意图，所有执行仍由本地后端校验。首次输出仅有格式或事实引用错误时，最多补充一次格式修复请求；总请求时限45秒，复验登录、运行及配置，修复不能改变原控制意图、控制值或把非法请求变成可执行指令。修复后仍不符合规则则拒绝执行。完整JSON代码围栏可安全去除，其余校验不放宽。兼容旧`campus-admin-v1`服务用于回退。

相关回答启用时须简短提及“路线认知、尝试意愿和引导触达”并引用实际可绕行群体；未启用时明确“当前未启用认知与意愿分组，本次仍按原选路规则分析”。任何优势都是当前估算，不能先称已验证更快，不能只看A就声称全网改善。AI保持登录、CSRF、密钥隔离、方案确认、并发版本校验和撤回机制。
