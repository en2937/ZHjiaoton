## 修改与构建

公共效果源文件是 `motion.mjs`。`build.mjs` 只更新以下文件开头的标记区域，其后的业务代码仍直接编辑：

- `../traffic-sandbox/dist/app.mjs`
- `../dify-integration-lab/public/student/app.mjs`

管理员助手从现有 `/app.mjs` 导入公共控制器，同页只加载一次GSAP。登录沿用独立构建器。

在项目根目录运行：

```powershell
node ui-motion/build.mjs
node admin-access/build-login.mjs
```

GSAP来源与许可证见 `../admin-access/vendor/gsap/PROVENANCE.md`。不要手改两个app模块的生成标记区。

## 验证与恢复

详见 `../SITE_MOTION_VALIDATION.md`。65项自动化检查通过，截图和浏览器记录在 `../ui-validation/site-motion/`。

修改前备份 `../_backup/20261015-114719-before-site-motion/`。恢复app模块、管理员助手、师生样式和登录源/生成资源即可撤回动效；本轮没有修改引擎、路网、共享后端、认证或AI协议。

`browser-fixture.mjs` 是独立浏览器验收工具：测试账号、独立沙盘、本地AI替身，4194/4195仅监听本机，45分钟自动停止。减少动态效果使用媒体查询与CSS替身，不代表实测系统设置切换。不要把fixture当成正式服务。

`prepare-restart.mjs` 只用于本次沙盘中断后的明确新建场景，不是自动恢复工具，也不能恢复丢失车辆和历史；正常维护不要运行它。

## 登录与管理员地图之间的镜头

`login-portal.mjs` 为登录成功后的两页交接源，与登录构建器和沙盘构建器共用。登录窗口淡出、地图变清晰并放大，正常跳转后缩小到真实画布的底图矩形；交接数据只在当前标签页短暂保存并消费一次。减少动态效果、异常和超时都回退到可用页面。验收、回退位置与浏览器范围见 `../admin-access/LOGIN_PORTAL_VALIDATION.md`。

当前镜头峰值为1.65倍。认证成功后才加载并解码既有3875×3379的 `/assets/Map.png`，准备成功才开始淡出和放大；最终清晰阶段清除滤镜，缩小落位继续使用同一原图。高清准备超过1.8秒或失败则直接导航，不放大900px缩略图。交接version2只接受这个固定同源路径；入场还需等原图解码和真实画布就绪。轻量缩略图仅用于平时登录背景。

高清版逐帧证据与预览在 `../ui-validation/login-portal-hd/`，原有验收证据保留。可用 `node ui-motion/check-login-portal.mjs --evidence=login-portal-hd` 核对对应的运行记录和资源；预览生成器接受证据目录作为可选参数。

`recover-login-checkpoint.mjs` 是本轮服务中断后的一次性完整检查点恢复工具，仅在4173拒绝连接时允许启动，先校验全部simulation字段，再保留runId恢复原服务器；已有服务运行时拒绝执行。它不恢复检查点之后未保存的进度，不用于正常页面构建。
